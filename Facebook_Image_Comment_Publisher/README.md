# Facebook Comment Publisher

برنامج Windows مستقل للتعليق على روابط منشورات Facebook باستعمال Meta Graph API. لا يغيّر Blogger أو Partage Social أو أي مشروع آخر.

## التشغيل
1. نزّل المجلد كاملاً.
2. شغّل `RUN.bat`.
3. أدخل User Access Token مرة واحدة ثم اضغط **جلب / تحديث الصفحات**. سيحفظه البرنامج محلياً على هذا الحاسوب.
4. ستظهر أسماء الصفحات وPage ID تلقائياً؛ اختَر الصفحة المطلوبة من اللائحة. لا توجد إضافة يدوية للصفحات.
5. اختَر صفحة واحدة فقط من اللائحة.\n6. اختَر CSV أو أنشئ واحداً من داخل البرنامج.\n7. اضغط **ابدأ التعليق** ووافق على رسالة التأكيد.

## إنشاء CSV من داخل البرنامج
- اضغط **＋ Nouveau / إنشاء CSV**.
- لكل سطر أدخل رابط منشور Facebook ونص التعليق؛ رابط الصورة اختياري.
- اضغط **＋ إضافة هاد السطر** وكرر العملية لإضافة سطور أخرى.
- عند الانتهاء اضغط **حفظ CSV**. سيختار البرنامج الملف الجديد تلقائياً ويضبط الأعمدة الثلاثة: `Photo_Link`, `Facebook_Link`, `Comment`.
- لا يكفي إدخال رابط الصورة وحده: يجب أن يكون رابط المنشور ونص التعليق موجودين حتى يحاول البرنامج إرسال التعليق.

## طريقة العمل السهلة\n1. جلب الصفحات من Meta أول مرة.\n2. اختيار صفحة واحدة.\n3. اختيار ملف CSV أو الضغط على إنشاء CSV جديد وإضافة رابط المنشور والتعليق.\n4. الضغط على ابدأ التعليق ومراجعة رسالة التأكيد.\n5. قراءة النتيجة في البرنامج أو فتح ملف النتائج داخل `output`.\n\n## CSV — اختيار الأعمدة مثل Blogger
يمكن أن تكون أسماء الأعمدة مختلفة. بعد اختيار CSV، عيّن من القوائم:
- عمود رابط الصورة (اختياري).
- عمود رابط منشور Facebook.
- عمود نص التعليق.

البرنامج يحفظ آخر اختيارات الأعمدة محلياً. يقبل CSV المفصول بفاصلة أو فاصلة منقوطة أو Tab.

## استقلال الصفحات
- كل صفحة عندها ملف حالة مستقل داخل `data/state/<PAGE_ID>.json` لمنع إعادة إرسال نفس السطر بعد نجاحه.
- نتائج كل صفحة تحفظ مستقلة داخل `output`.
- كل تشغيل يستعمل صفحة واحدة فقط. اختَر الصفحة التي تملك المنشور أو لديها صلاحية التعليق عليه. لا تختَر صفحة أخرى لمجرد أنها موجودة في القائمة.
- User Access Token وأسماء الصفحات وPage Access Tokens تحفظ محلياً داخل `data/settings.json` على حاسوبك. لا ترفع هذا الملف إلى GitHub ولا تشاركه. عند فتح البرنامج مرة أخرى سيبقى User Token محفوظاً، ويمكنك الضغط على تحديث الصفحات لجلب أحدث القائمة والتوكنات.

## صلاحيات Meta وحدودها
- جلب الصفحات يتطلب User Access Token مع صلاحية مثل `pages_show_list`.
- التعليق يتطلب Page Access Token وصلاحيات Meta المناسبة، وغالباً `pages_manage_engagement` وصلاحيات قراءة/وصول مناسبة للصفحة.
- Meta قد ترفض التعليق على منشورات لا تديرها الصفحة أو لا تسمح بها الصلاحيات أو نوع المنشور. وجود Token لا يضمن قبول كل تعليق.
- البرنامج يتعامل مع روابط المنشورات التي يمكن استخراج Graph object ID منها. بعض روابط `pfbid` والروابط المختصرة لا تكشف ID رقمي، وقد تحتاج رابطاً آخر.
- `Photo_Link` يُرسل كـ `attachment_url`؛ إذا رفضته Meta سيظهر سبب الفشل في ملف النتائج.

## الملفات
- `RUN.BAT`: ملف التشغيل الوحيد على Windows.
- `comments_template.csv`: نموذج CSV.
- `data/settings.json`: إعدادات الصفحات محلياً (حساس).
- `data/state`: سجل مستقل لكل صفحة.
- `output`: نتائج كل صفحة.

استعمله للتعليقات الملائمة فقط، وتجنب التكرار والإزعاج واحترم قيود Meta.
