Facebook Page Creator — أداة مستقلة لتجهيز صفحات Facebook من CSV

التشغيل:
1) نزّل هذا المجلد وحده من GitHub أو حمّله كاملاً.
2) شغّل RUN_PAGE_CREATOR.bat بنقرتين.
3) حمّل ملف CSV.
4) اربط أعمدة CSV بخانات الصفحة (الاسم، الوصف، النبذة، التصنيف...).
5) تنقّل بين الصفوف أو اضغط «تجهيز جميع الصفحات من CSV».
6) النتائج داخل prepared_pages.

يمكن اختيار أي عمود من CSV لكل خانة، بالعربية أو الإنجليزية.
الأداة تجهّز ملفات معلومات الصفحات والصور محلياً؛ إنشاء الصفحة النهائي يتم يدوياً من Facebook.
لا تغيّر أي ملف في مشروع Blogger أو إعدادات Facebook.
تحتاج Python 3 مع Tkinter فقط، ولا تحتاج مكتبات pip إضافية.
