# Blogger theme version control

Export the current Blogger theme XML from Blogger: Theme → menu → Backup/Download. Store the exported XML in this folder to keep a versioned copy in GitHub.

To apply a changed template, use Blogger → Theme → Restore/Upload. The public Blogger API does not provide a general endpoint for replacing the theme, so this final step is manual. Review mobile layout, widgets, menus, and ad placements before applying any template.
