DEALZONE CSV SEO TOOL

WHAT IT DOES
- Lets you choose any one CSV file from your computer.
- Processes every product row in that CSV.
- Adds SEO_Description and Hashtags columns.
- Keeps the original columns and values.
- Saves a NEW file next to the original with the name *_SEO.csv.
- Does not overwrite or delete your original CSV.
- Does not need Gemini API, extra Python packages, or internet access.

HOW TO USE
1. Extract the downloaded ZIP.
2. Open the csv-seo-tool folder.
3. Double-click RUN.bat.
4. Choose the CSV file you want.
5. Wait for the success message.
6. Find the new *_SEO.csv file beside your original CSV.

NOTES
- This version creates SEO descriptions using built-in category templates; it does not call an AI API.
- The original CSV remains unchanged.
- Clothing CSVs are treated as men's or women's clothing based on their filename/content.
