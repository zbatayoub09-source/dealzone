DEALZONE FACEBOOK PAGE LIKE HELPER

START
1. Double-click RUN_JAIME.bat.
2. Paste a Facebook User Access Token with permission to list your Pages (pages_show_list).
3. Click Load my Pages. The app loads all pages returned by Facebook, including more than 10 pages.
4. Use Select All / Select None or Ctrl/Shift to choose the managed Pages.
5. Paste the URL of the Facebook Page you want to interact with.
6. Click OPEN TARGET PAGE IN FACEBOOK.
7. In Facebook, switch to each selected Page profile manually and use Like/Follow if Facebook offers it.

IMPORTANT
- This is a manual browser helper. It does not automate, mass-submit, or simulate Likes/ Follows.
- Facebook controls whether a Page profile can like/follow another Page. Some Page types or account configurations may not show the Like option.
- The access token is used only in memory to load the Page names. It is not written to disk or included in GitHub.
- If Facebook returns fewer Pages than expected, check the token, Page access, and pages_show_list permission.
- Python 3.10+ recommended. Uses only Python standard library and Tkinter.
